# リポジトリ整理 設計

## 目的

GitHubへ公開する成果物と、ローカル作業用のレビュー資料・生成物を分離し、リポジトリのルートを保守しやすくする。

## 方針

- `CC_REVIEW_FEEDBACK*.md` 9件を `.local/reviews/` へ移動する。
- `.local/` を `.gitignore` に追加し、レビュー資料はローカルに保持するがGit管理対象外にする。
- 既存のGit履歴は書き換えない。
- 既に無視されているXcode生成物、ビルド成果物、作業ツリー等は維持する。
- `.gitignore` は「OS」「Xcode/ビルド」「ローカル作業用」「プロジェクト固有の非公開資料」に分類する。

## 成功条件

- ルート直下からレビュー資料がなくなる。
- `git status --short` にレビュー資料や`.local/`が表示されない。
- ソースコード・テスト・公開ドキュメントの追跡状態は変わらない。
- `.gitignore` の内容から、無視対象の理由と範囲が読み取れる。
