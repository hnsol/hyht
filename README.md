# Hyht

Hyht is an iOS app project consisting of a main app target and a WidgetKit
extension that share data through an App Group container, backed by a local
Swift Package (`HyhtCore`) that holds cross-target logic and resources. This
repository currently contains only the Phase 1 project scaffolding: an
XcodeGen-generated Xcode project, minimal app/widget UI, and an App Group
read/write probe used to verify the whole pipeline end to end.

## Prerequisites

- Xcode 26.5+
- XcodeGen 2.46.0 (`brew install xcodegen`)
- iOS Simulator: iPhone 17 (latest iOS, used for primary verification)
- iOS Simulator: iPhone 15 with the iOS 17.0 runtime installed (used to verify
  the minimum supported OS, since this project targets iOS 17.0+)

## Project generation

The Xcode project (`Hyht.xcodeproj`) is not checked into git. Generate it with:

```bash
cd /Users/masatora/Documents/MyDevelop/260100/260802_hyht
xcodegen generate
```

## Verified commands

The following commands were run against this project and completed
successfully:

```bash
# Generate the Xcode project from project.yml
xcodegen generate

# List available schemes
xcodebuild -list -project Hyht.xcodeproj

# Run HyhtCore's unit tests (via the Hyht scheme's test action, which
# references the HyhtCore package's test target)
xcodebuild test -project Hyht.xcodeproj -scheme Hyht \
  -destination 'platform=iOS Simulator,name=iPhone 17'

# Build the app (+ embedded widget) for the latest iOS Simulator
xcodebuild build -project Hyht.xcodeproj -scheme Hyht \
  -destination 'platform=iOS Simulator,name=iPhone 17'

# Build the app (+ embedded widget) for the minimum supported iOS version
xcodebuild build -project Hyht.xcodeproj -scheme Hyht \
  -destination 'platform=iOS Simulator,name=iPhone 15,OS=17.0'
```

Note: `xcodebuild -list` shows two schemes, `Hyht` and `HyhtCore`. The
auto-discovered `HyhtCore` scheme (created implicitly for the local Swift
package) is not configured for the test action by default, so
`HyhtCoreTests` is run through the `Hyht` scheme instead, which explicitly
includes the package's test target in its Test Action (see `project.yml`'s
`schemes.Hyht.test.targets`).

## toFixed golden fixture

`HyhtCore`'s countdown formatting must match JavaScript's
`Number.prototype.toFixed` exactly (the app is a port of a Scriptable widget).
The expected values are generated by running `toFixed` in Node.js rather than
written by hand, because floating point makes them counter-intuitive (for
example `(9.995).toFixed(2)` is `"9.99"`, not `"10.00"`).

```bash
# Regenerate Packages/HyhtCore/Sources/HyhtCore/Resources/tofixed-fixture.json
node Scripts/generate-tofixed-fixture.mjs
```

The generator is deterministic: re-running it on an unchanged script produces a
byte-identical file. `JSToFixedGoldenTests` reads the fixture from
`Bundle.module` and compares every case against `jsToFixed(_:digits:)`.

## App Group setup

This project uses the App Group identifier `group.com.masatora.hyht`,
declared in both `App/Hyht.entitlements` and `Widget/HyhtWidget.entitlements`.

- For Simulator builds (as verified above), no Developer Portal registration
  or Team assignment is required. The targets are configured with ad-hoc
  signing (`CODE_SIGN_IDENTITY = "-"`, no Team). Note: signing must NOT be
  fully disabled (`CODE_SIGNING_ALLOWED = NO` breaks entitlement embedding —
  the App Group container becomes unavailable, and the missing
  CFBundleVersion also prevents `simctl install`). With ad-hoc signing the
  Simulator honors the App Group entitlement locally (verified via
  `xcrun simctl get_app_container booted com.masatora.hyht groups`).
- For running on a physical device, the App Group
  (`group.com.masatora.hyht`) must be registered under the relevant Apple
  Developer account, and the app/widget targets must be assigned a
  development Team in Xcode. With automatic signing enabled, Xcode will
  register the App Group capability and provisioning profile automatically
  the first time you build to a device with a Team selected — no manual
  Developer Portal steps should be necessary beyond having Team access.
